Network shares

Connect Windows (SMB) or NFS file shares, such as a NAS or another computer's shared folder. A share is either for backups (only the administrator can see inside it, and the Backups page can store copies on it) or for the File manager (everyone with an account on this machine can read it, nobody can change it from here).

SMB support is not installed on this machine. Install the package cifs-utils on the Packages page, then come back.

NFS support is not installed on this machine. Install the package nfs-common on the Packages page, then come back.

Add a share

Leave the user name empty only for a share that allows guests.

SMB passwords are stored in a file only root can read and are never shown again. NFS needs no password here: the server decides who may mount an export, usually by this machine's address, so allow this machine's address in the server's exports. If the server squashes root, a backup share may refuse the write; use no_root_squash for the backup export. Shares are not connected at start-up: use Connect, or let a backup connect its share when it runs. They appear under /mnt/adminpanel/NAME. Use Test to check the address and password without leaving the share connected.
