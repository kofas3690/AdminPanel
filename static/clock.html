Date & time

The clock, time zone, network time and name of this machine. The time itself is kept right by network time; there is no box to type a time into, because a hand-set clock drifts and breaks certificates and logins.

Network time

Network time (NTP) sets the clock from time servers over the internet. It needs a time service such as systemd-timesyncd or chrony on this machine.

Time zone

Logs and schedules use this zone. Running programs may need a restart to notice a change.

Hostname

Lower-case letters, digits and hyphens. The name shown in your prompt and on the network changes at once. Other machines that reach this one by name, and the browser address if you use the name, need the new name too.
