SSH keys

An SSH key lets a person sign in over SSH without typing a password, and is much harder to guess than a password. Each person makes a key pair on their own computer (ssh-keygen -t ed25519) and gives you the public half, the file ending in .pub. Never ask for or paste the private key. Once keys work, you can turn password sign-in off in the SSH settings (see the Security check).
