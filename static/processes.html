Processes

Everything running on this machine. Ending a process is limited to ordinary programs: processes owned by root, the panel itself and core system processes are shown but can't be ended here. To stop a service, use the Services page.

PIDNameUser CPU %MemoryState StartedCommand

CPU % is the share of one processor core, as in top, so a busy process on a 4-core machine can show up to 400. End asks the program to stop (it can save its work). Force quit stops it at once and should be used only when End has not worked.
