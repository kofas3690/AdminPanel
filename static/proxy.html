Proxy

An outgoing proxy for this server's own downloads: software updates and new login sessions.

Good to know

Proxy addresses can't contain a user name or password, because these settings are readable by every user on the server. Supported schemes are http, https, socks5 and socks5h.

Programs that are already running keep their old settings, and services started by the system don't read /etc/environment. Only apt and new logins pick up changes straight away.
