Swap

Swap is space on the disk that the machine uses when it runs out of memory (RAM). Without it, a machine that runs out of memory starts killing programs. Small cloud machines often have none. The swap file is always /swapfile.

Swappiness

How eagerly the machine moves memory to swap, from 0 (avoid it) to 100 (use it freely). The default is 60. Servers often use 10.
